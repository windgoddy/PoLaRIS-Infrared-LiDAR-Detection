# HaloNet 研究进展汇报
**汇报日期**：2026年3月
**研究方向**：基于粗糙边界框的红外小目标弱监督像素级分割
**目标期刊**：IEEE Transactions on Image Processing (CCF-A)

---

## 一、问题定义

### 研究背景
红外小目标检测（IRSTD）在海洋监控、导弹预警等领域至关重要。深度学习方法（DNANet、UIU-Net 等）在全监督设置下性能优秀，但**像素级掩码标注成本极高**，严重制约了大规模数据集的构建。

### 现有弱监督方法的局限

| 方法 | 监督形式 | 核心问题 |
|------|---------|---------|
| LESPS (CVPR 2023) | 单点标注 | 微小目标中心难以精准点击；多轮迭代训练开销大 |
| PAL (ICCV 2025) | 单点标注 | 主动学习循环需要人工干预；实际部署成本高 |
| **HaloNet (Ours)** | **边界框标注** | **上游 YOLO/雷达系统天然输出 box，无需额外标注** |

### 核心挑战
边界框内 **>99% 的像素是背景杂波**（对于典型的 <9px² 目标）。
直接用整个框训练会导致**表征坍塌**——网络学习预测整个框区域。

## 二、方法概述（HaloNet）

### 总体流程

```
输入 IR 图像 + YOLO Box 标注
         │
         ▼
┌─────────────────────────────────────────────────────┐
│              物理先验伪标签生成器（无参数）               │
│                                                     │
│  Step 1: Context Box 膨胀 (expand_ratio=1.5)        │
│          ├── 统计域：框外背景 → 估计 μ_ctx, σ_ctx    │
│          └── 作用域：框内像素 → 计算 SNR 权重         │
│                                                     │
│  Step 2: B-SNR 后验掩码                              │
│          W(i) = σ(τ · (I(i) - μ_ctx) / σ_ctx)      │
│          [C 组实验：直接使用 B-SNR 作为伪标签]          │
│                                                     │
│  Step 3: PAG 物理锚定高斯精炼                         │
│          p* = argmax(W)          ← 物理热点（非几何中心）│
│          FWHM区域 = {i: W(i) ≥ W(p*)×0.5}           │
│          σ = 1.5 × √(Σ_FWHM W(i)·d²_i / Σ_FWHM W(i))│
│          P(i) = W(i) × exp(-d²_i / 2σ²)            │
│          [D 组实验：使用 PAG 软标签]                   │
└─────────────────────────────────────────────────────┘
         │ 伪标签 (Soft Mask)
         ▼
┌──────────────────────┐
│  任意 IRSTD 网络      │  ← Model-Agnostic（模型无关）
│  DNANet / ACM / ALCNet│
│  + SoftIoU Loss       │
└──────────────────────┘
         │
         ▼
    分割预测输出
```

### 关键设计原则

1. **零参数、无迭代**：伪标签生成完全基于物理公式，不引入任何可学习参数
2. **统计域与作用域分离**：背景统计从膨胀 Context Box 计算，避免目标污染估计
3. **物理热点锚定**：高斯中心是 B-SNR argmax（目标最强响应点），而非几何中心

### 方差污染理论边界

当目标极小时（target-to-box ratio α → 0），B-SNR 性能下界由以下公式给出：

$$\hat{\sigma}^2_\mathrm{ctx} \approx \sigma^2_0 + \alpha(1-\alpha)\Delta\mu^2$$

其中 Δμ 为目标与背景的强度差，σ₀ 为真实背景方差。
当 α < 0.05 且目标极亮（Δμ >> σ₀）时，方差估计被严重污染，SNR 趋近于 0。
**这从理论上解释了 NUDT-SIRST（极小目标数据集）上的性能差距。**

## 三、实验设计

### 实验分组

| 组别 | 标签来源 | 含义 |
|------|---------|------|
| **A 组** | GT 像素掩码 | 全监督上界（理论天花板） |
| **B 组** | LESPS 伪标签 | 单点弱监督基线对比 |
| **C 组** | B-SNR 掩码 | 本文方法（纯 SNR 后验） |
| **D 组** | PAG 软标签 | 本文方法（SNR + 物理高斯精炼） |

### 数据集

| 数据集 | 图像数 | 目标大小 | 特点 |
|--------|------|---------|------|
| **NUAA-SIRST** | 427 | 中等（~30px²） | SCR 适中，目标较明显 |
| **NUDT-SIRST** | 1,327 | 极小（<9px²） | 最具挑战性，目标极暗 |
| **IRSTD-1K** | 1,000 | 中小（~15px²） | 多样化背景 |

### 网络骨干

| 骨干网 | 架构类型 | 参数量 | 来源 |
|--------|---------|--------|------|
| **DNANet** | 密集嵌套 UNet++ + Res-CBAM | 大 | TIP 2022 |
| **ACM** | 非对称非局部模块 | 中 | WACV 2021 |
| **ALCNet** | 局部对比度注意力 FPN | 中 | TGRS 2021 |

## 四、实验结果

### P1 组：DNANet 骨干（完整数据）

| 数据集 | A (GT 全监督) | B (LESPS) | C (B-SNR) | **D (PAG)** | PAL 参考 |
|--------|-------------|-----------|-----------|------------|---------|
| NUAA-SIRST | 72.84% | 55.17% | 63.12% | **70.69%** | 63.46% |
| NUDT-SIRST | 95.07% | 57.39% | 56.12% | **62.97%** | 73.10% |
| IRSTD-1K | 70.94% | 50.90% | 60.91% | **60.75%** | 60.72% |
| **平均** | **79.62%** | **54.49%** | **60.05%** | **64.80%** | **65.76%** |

**关键观察**：
- NUAA：PAG (70.69%) 显著超越 PAL (63.46%)，**+7.23%**，逼近全监督上界（-2.15%）
- IRSTD：PAG (60.75%) ≈ PAL (60.72%)，**基本持平**
- NUDT：PAG (62.97%) < PAL (73.10%)，**-10.13%**（由方差污染理论解释）

### P2 组：ACM / ALCNet 骨干（部分数据，~1000/1500 epoch）

| 数据集 | 骨干 | A (GT) | C (B-SNR) | D (PAG) | 保留率 D/A |
|--------|------|--------|-----------|---------|-----------|
| NUDT-SIRST | ALCNet | 65.76% | 51.95% | **55.81%** | **84.9%** |
| NUDT-SIRST | ACM | 64.85% | 51.24% | **53.37%** | **82.3%** |
| NUAA-SIRST | ALCNet | - | - | - | 训练中 |
| NUAA-SIRST | ACM | - | - | - | 训练中 |
| IRSTD-1K | ALCNet | - | - | - | 刚启动 |
| IRSTD-1K | ACM | - | - | - | 刚启动 |

**关键观察**：
- PAG 在所有骨干上**一致优于** B-SNR（DNANet +6.85%，ALCNet +3.86%，ACM +2.13%）
- **模型无关性得到初步验证**
- NUDT 保留率 82-85%：用最廉价的框标注激发了老旧模型 85% 的全监督性能

## 七、与现有方法的对比优势总结

| 维度 | LESPS | PAL | **HaloNet (Ours)** |
|------|-------|-----|-------------------|
| 监督形式 | 单点 | 单点（主动选择） | **边界框** |
| 标注来源 | 人工点击 | 人工点击+迭代 | **YOLO/雷达自动输出** |
| 训练方式 | 多轮迭代更新 | 主动学习循环 | **单次前向，无迭代** |
| 额外参数 | 无 | 无 | **无** |
| 模型无关 | 部分 | 部分 | **是（3骨干验证）** |
| NUAA mIoU | 55.17% | 63.46% | **70.69%** |
| IRSTD mIoU | 50.90% | 60.72% | **60.75%** |
| NUDT mIoU | 57.39% | 73.10% | **62.97%** |
| 理论分析 | 无 | 无 | **有（方差污染边界）** |
